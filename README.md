# Reference Books

Shared academic and career references across every semester. The Reference-Books folder name and root location are unchanged.

## Naming and preservation

Use actual document titles and verified editions. Semester files are copied, never moved; duplicates between this library and modules are intentional. Samples/excerpts are labelled. Unverified authors/editions are not invented. The catalogue records source paths, original filenames and hashes.

The older local Artificial Intelligence fourth-edition copy was replaced with the fuller 2,145-page semester copy: all 2,124 nonempty original page texts matched. The older copy was sent to Windows Recycle Bin. No semester originals were changed.
