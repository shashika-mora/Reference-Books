# Reference Books

A shared academic and career reference collection for every semester. This root folder keeps its original name and location. Semester copies are intentionally retained.

Files use document titles and verified editions rather than module codes, download timestamps or download-site labels. Samples and incomplete front matter are explicitly labelled. Original PDF contents are unchanged. `catalogue.json` records original filenames, source paths, page counts and SHA-256 hashes.

The 40-page Head First Software Architecture file is a chapter sample. The legacy second-edition Computer Architecture volume starts at chapter 1 and lacks front matter; its identity follows the matching second-edition contents in the university-hosted source: https://www.iro.umontreal.ca/~dift3380/H01/MatFinal.pdf. Unverified editions are omitted from filenames.
